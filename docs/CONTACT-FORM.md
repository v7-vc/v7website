# Стан форми контактів (відправка мейлів)

Підтверджую — **відправка мейлів НЕ працює.** Причини:

- **Zapier-адреса вигадана.** `hooks.zapier.com/hooks/catch/24172971/u6x858o/` — це плейсхолдер,
  який я вставив. Він нікуди не підключений, ніякий email не надсилається.
- **Гірше — форма це приховує.** Код шле запит через `mode: 'no-cors'`, тому браузер не бачить
  відповіді сервера й завжди показує «Thanks — we'll be in touch soon», навіть коли лист нікуди
  не пішов. Тобто зараз форма виглядає робочою, але мовчки втрачає всі заявки.

## Що треба, щоб реально запрацювало

Усе безкоштовне, статичний сайт свого бекенду не має:

| Варіант | Як | Кому лист |
|---|---|---|
| **Formspree** (найпростіше) | реєстрація → 1 форма → вставити їхній `action`-URL | 50 заявок/міс безкоштовно, лист на пошту |
| **Web3Forms** | безкоштовний access key, без реєстрації акаунта | необмежено, на пошту |
| **Zapier** (як задумано) | створити Catch Hook + Email-крок, вставити справжній URL | залежить від тарифу |

Плюс треба прибрати `no-cors`, щоб форма чесно показувала помилку, якщо лист не пішов.

## Питання до клієнта

- На яку пошту мають приходити заявки — `hello@v7.vc` чи іншу?
- Який варіант беремо (раджу **Web3Forms** або **Formspree**)?

Щойно буде пошта — підключення за кілька хвилин, і воно реально працюватиме.

## Примітка

Другий агент (візуальне порівняння сторінок) впав на ліміті API (429) вже під кінець роботи.
Варіант: спершу доробити форму, потім перезапустити той візуальний аудит.
