# RULES — обов'язкові правила роботи в цьому репо

## 1. Перед кожним завданням — скіли
Перед виконанням будь-якого завдання перевір, чи є відповідний скіл
(Superpowers чи інший), і використовуй його:
- нова фіча/компонент → `superpowers:brainstorming`
- написання коду → `superpowers:test-driven-development`
- баг/неочікувана поведінка → `superpowers:systematic-debugging`
- перед "готово" → `superpowers:verification-before-completion`
Якщо для задачі потрібен скіл, якого немає — скажи, який саме, і дай команду
для встановлення, щоб користувач його докачав.

## 2. Перед кожною відповіддю — стисло
Кожен output користувачу — скорочений: результат і суть, без розлогих пояснень.
Розписувати детально ТІЛЬКИ якщо користувач сам попросить ("розпиши",
"детальніше", "поясни").
