# Проєкт: Перенос сайту v7.vc з Framer у код

> Цей файл — повний контекст задачі. Прочитай його першим. Мова спілкування з клієнтом і замовником — українська.

---

## 1. Суть задачі

Перенести сайт **https://v7.vc** (сайт венчурного фонду V7) з білдера **Framer** на чистий код і задеплоїти на безкоштовний хостинг. Замовниця (кінцева клієнтка) після переїзду має платити **тільки за домен**, а не за підписку Framer.

Виконавець — **студент**, робить такий перенос уперше/один з перших. Пообіцяв клієнтці зробити **1:1** (піксель-в-піксель, з анімаціями). Дедлайн — **~2 тижні**, орієнтовно по кілька годин на день (реалістично ~20–28 год роботи).

**Головний ризик:** обіцянка «1:1». Framer-сайти виглядають дорого саме через скрол-анімації/ефекти — їх відтворення в коді забирає найбільше часу. Треба або реально відтворити ключові анімації, або м'яко переузгодити обсяг із клієнткою на старті.

## 3. Рекомендований технічний план

- **Стек:** Astro (ідеально для статики + шаблонні сторінки) або Next.js. Рекомендація — **Astro**.
- **8 сторінок проєктів — НЕ вручну.** Один шаблон + дані (JSON/Markdown/Content Collections) → сторінки генеруються. Економія ~2 днів.
- **Порядок роботи:** спершу структура/верстка всіх блоків → адаптив → анімації в кінці. Щоб навіть без частини ефектів сайт виглядав готовим.
- **Анімації:** відтворювати через CSS + бібліотеку (Framer Motion / GSAP / Intersection Observer). Це ~60% часу при «1:1».
- **Форма:** Framer робив обробку сам; у коді підключити Formspree / Web3Forms / Netlify Forms (15–30 хв). Треба знати, куди зараз падають заявки.

## 4. Хостинг і домен

- Домен **v7.vc** — власний (не піддомен Framer), зареєстрований на **name.com**.
- Зона `.vc` недешева (~$30–60/рік) — це клієнтка й так платить.
- **Хостинг коду:** Vercel / Netlify / Cloudflare Pages — безкоштовно, HTTPS, деплой з GitHub.
- **Переприв'язка домену:** у name.com змінити DNS-записи (A / CNAME) з Framer на новий хостинг. ~10 хв + до 24–48 год поширення DNS.
- **Downtime ≈ 0:** спершу повністю зробити й протестувати новий сайт на тимчасовому домені, і тільки коли готово — перемкнути DNS.
- **Що клієнтка втратить:** Framer-аналітику, візуальний редактор контенту, вбудовану обробку форми. Якщо вона сама редагувала тексти у Framer — попередити (за потреби підключити простий CMS типу TinaCMS/Sanity).

### Доступ до name.com
Був крок «Unrecognized device» при вході (захист нового пристрою): натиснути «Send me the code» → взяти код із пошти `ko***@***.com` → ввести на сайті. DNS-налаштування шукати в панелі домену після входу.

## 6. Дані, які треба зібрати з Framer (у виконавця фул-доступ)

**Мінімум, щоб почати:** пункти 1, 2, 4, 6. Решту (тексти, зображення) можна витягти з опублікованого сайту.

1. **Шрифти** — назви всіх шрифтів (Typography), скріни налаштувань для заголовків/тексту (розмір, вага, letter-spacing, line-height).
2. **Кольори / токени** — скрін панелі Colors/Styles з hex-кодами.
3. **Зображення/ассети** — усі картинки в макс. якості (логотипи проєктів, фото команди, іконки, фони). Логотип V7 окремо, бажано SVG.
4. **Анімації (найважливіше для 1:1)** — відео-запис екрана зі скролом кожної сторінки: що з'являється, звідки, як швидко, паралакс, hover-ефекти.
5. **Адаптив** — скріни кожної сторінки в 3 розмірах: Desktop / Tablet / Mobile.
6. **Контактна форма** — куди зараз падають заявки (пошта `hello@v7.vc`? Google Sheets? Notion?).
7. **Тексти** — весь контент (можна витягти із сайту).
8. **SEO** — favicon, og-картинка, title/description кожної сторінки.

---

## 7. Наступні кроки в цьому воркспейсі

1. Підняти каркас Astro-проєкту.
2. Витягнути контент і структуру з опублікованого v7.vc (HTML/CSS/зображення).
3. Зверстати блоки головної → адаптив → анімації.
4. Зробити шаблон сторінки проєкту + дані на 8 компаній.
5. Підключити форму.
6. Задеплоїти на Vercel/Netlify, потім переприв'язати DNS у name.com.

> Коли відкриєш цей воркспейс — почни з того, що попроси у виконавця дані з розділу 6 (мінімум 1, 2, 4, 6) і паралельно витягни контент із сайту.
