# Working agreements — v7.vc project

## 1. Concise by default
Keep every answer short and to the point: state what changed / the result, not the
full reasoning or step-by-step. Expand into detail ONLY when explicitly asked
("розширь", "детальніше", "поясни", "expand").

## 2. Use Superpowers during implementation
Before/at the start of implementation work, invoke the relevant Superpowers skill and
announce it ("Using [skill]…"):
- `superpowers:brainstorming` — before building a new feature/component or changing behavior
- `superpowers:test-driven-development` — when writing feature or bugfix code
- `superpowers:systematic-debugging` — for any bug, test failure, or unexpected behavior
- `superpowers:verification-before-completion` — before claiming something is done/fixed
- `superpowers:requesting-code-review` — before merging significant work

## 3. Grill me when unclear
If a request is ambiguous, or a decision could reasonably go multiple ways, STOP and
ask clarifying questions (grill me) instead of guessing. Prefer AskUserQuestion or the
brainstorming skill over assumptions.
